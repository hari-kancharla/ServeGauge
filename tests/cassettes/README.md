# OpenRouter fixture provenance

`openrouter_endpoints_public.json` is an unpaid public endpoint-metadata capture,
with source URL and UTC retrieval date. Only factual fields used by discovery are kept.

The other `*_contract.json` files are synthetic schema/behavior examples using fictional
providers. They are **not** live generation records or evidence of provider behavior.
Authenticated generation recording and the benchmark column are pending an owner key.
No third-party benchmark questions, model outputs, API keys or account records are included.
Every default test replays fixtures through an in-memory HTTP transport and opens no sockets.
