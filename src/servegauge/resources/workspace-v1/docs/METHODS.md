# ServeGauge workspace methods and limits

This workspace starts offline, with every live and GPU budget set to zero.
Initialization makes no model calls and downloads no assets. Run `servegauge
setup-cache` separately to download the public, checksum-verified tokenizer.

Checks measure explicit application requirements. Every inferential result carries
its sample count, interval, margin and reference tier. Insufficient or unavailable
evidence is INCONCLUSIVE; absent measurements are not zero or passing evidence.
Comparative decisions require a compatible reference and matched design. Configured
margins are declared policies, not provider quality certificates.

Fingerprints compare response distributions. A detected difference does not identify
model weights, quantization, hardware, intent or a unique root cause. Correlated
responses and repeated cache groups reduce effective information; missing logprobs
cannot establish logprob equivalence. FP4 needs separately installed optional
embedding dependencies and pinned local model assets. It is not downloaded by init.

Initialization includes no empirical qualification or historical data. An explicit
reviewed evidence root can bind the existing frozen scripted-text qualification
only when its code, runtime and evidence hashes all verify. This qualification is
limited to its declared scripted mock process. It does not qualify real providers.
The transport admission registry starts empty. Full research studies require the
source distribution and its evidence corpus, not this lightweight workspace.

Raw captures, reservations, reports, site views, diagnosis bundles and dataset
snapshots remain local until a separately authorized owner action. Generated item
text has declared licensing; unknown/external benchmark text is aggregate-only in
numeric exports. Public export preflight rechecks selected inputs and reply gates;
scripted mock data is never approved for public upload. Owner assertions of contact
or reply are not independently verified delivery.

All paid traffic must pass the normal runner, estimates, reservations and caps.
Never put credentials in configuration, command arguments, captures or reports.
The CLI uses named environment variables for owner-configured credentials.
No live round, GPU session, schedule activation, contact or publication is enabled
by initialization. The public source repository retains the evidence used by its tests,
reproduction instructions, licenses and measurement limitations.
